# Identidad visual del blog

El blog comparte la identidad de la landing de Restaura tu Matrimonio: una lectura serena, cálida y clara. Los colores principales están definidos en `app/globals.css`.

| Función | Color | Uso |
| --- | --- | --- |
| Verde profundo | `#263A31` | Titulares, texto principal y pie de página |
| Vino | `#713F50` | Acciones principales, enlaces y énfasis puntuales |
| Vino oscuro | `#563041` | Estados hover y paneles de cierre |
| Marfil | `#FFFCF7` | Fondo de lectura y tarjetas |
| Pergamino | `#F7F1E9` | Portadas de sección, artículo y botones claros |
| Salvia | `#E8EDE7` | Herramientas y avisos de ayuda práctica |
| Tierra | `#86604F` | Etiquetas y detalles de apoyo; evitarlo como fondo de botones con texto oscuro |

La tipografía usa **Cormorant Garamond** para títulos y **Manrope** para lectura y navegación. Mantener el vino como señal de acción y reservar el verde para la estructura evita competir con el contenido de los artículos.

Contrastes comprobados: vino sobre blanco `8,30:1`, tierra sobre pergamino `4,92:1`, texto secundario sobre marfil `7,20:1` y títulos claros del pie sobre verde profundo `6,70:1`.
